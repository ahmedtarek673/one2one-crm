# One2One CRM

A comprehensive CRM system for lead management, sales tracking, and administrative reporting.

## Features

- **Lead Management**: Track and manage leads efficiently.
- **Sales Representative Dashboard**: Specialized dashboard for sales teams to manage their assigned leads.
- **Administrative Dashboard**: Overview of system performance and lead distribution.
- **Notion Integration**: Sync chat logs and appointments with Notion.
- **AI-Powered**: Integrated with AI for intelligent lead processing.

## Technologies

- **Frontend**: React, Vite, TypeScript, Tailwind CSS, shadcn-ui
- **Backend**: Supabase (PostgreSQL, Auth)
- **Deployment**: Firebase / Vercel

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm i`
3. Set up environment variables in a `.env` file.
4. Run the development server: `npm run dev`
