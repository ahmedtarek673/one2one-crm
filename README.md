# One2One CRM

A CRM system for lead management, sales tracking, and administrative reporting.

## Highlights

- Lead management and qualification workflows
- Sales representative dashboard for assigned leads
- Administrative dashboard for performance and distribution reporting
- Notion integration for chat logs and appointments
- AI-assisted lead processing

## Tech stack

React · Vite · TypeScript · Tailwind CSS · shadcn/ui · Supabase · PostgreSQL

## Getting started

1. Clone the repository.
2. Install dependencies with <code>npm install</code>.
3. Configure the required environment variables in <code>.env</code>.
4. Start the development server with <code>npm run dev</code>.
